## 🚀 Featured Projects

<details>
<summary><b>🛡️ Shieldfied — Cybersecurity Awareness Platform</b></summary>
<br/>

A full-stack cybersecurity awareness platform built on the MERN stack, designed to make security concepts accessible through interactive, simulated learning modules rather than static content.

**Why it matters:** Security awareness is often taught passively through text; Shieldfied instead uses simulated threat-detection modules so users learn by interacting with realistic scenarios.

**Technical implementation:** The frontend is built in React.js with a glassmorphism-based UI focused on usability and clarity. The backend uses Node.js and Express.js to serve simulated threat-detection logic, with MongoDB handling persistence for user progress and modules.

**Engineering decisions:** A component-driven React architecture was chosen to keep the simulated modules reusable and independently testable, while a REST API layer keeps the frontend and backend cleanly decoupled.

<summary><b>💡 Smart AI Bulb Socket — IoT Energy Monitoring System</b></summary>
<br/>

An IoT-based smart bulb socket enabling Wi-Fi remote control and real-time energy monitoring, with AI-driven automation for lighting schedules.

**Why it matters:** Household energy waste from lighting left unnecessarily on is a common, solvable problem — this project addresses it through automated, data-driven control rather than manual switching.

**Technical implementation:** Built on the ESP32 microcontroller with integrated IoT sensors for real-time power/usage monitoring, programmed in C++. AI-driven analysis was layered on top of sensor data to automate lighting schedules.

**Engineering decisions:** ESP32 was chosen for its built-in Wi-Fi and low power footprint, making it well suited for always-on home automation hardware.

| Attribute | Details |
|---|---|
| Stack | ESP32, IoT Sensors, C++ |
| Scale | Single-device prototype |
| Performance | Reduced energy consumption by approximately 20% (project-reported) |
| Security | Wi-Fi based remote control |
| Impact | Automated, energy-efficient lighting control |
| Repository | [github.com/Abhinaw321](https://github.com/Abhinaw321) |

</details>

<details>
<summary><b>📄 IntelliHire AI — AI-Powered Resume Analyzer & ATS Optimizer</b></summary>
<br/>

An AI-powered resume analyzer that provides ATS scoring and personalized improvement suggestions by combining PDF parsing, job-description matching, and generative AI.

**Why it matters:** Applicant Tracking Systems filter out qualified candidates due to formatting or keyword mismatches; IntelliHire AI helps close that gap with actionable, AI-generated feedback.

**Technical implementation:** Built with a React.js frontend styled using Tailwind CSS, a Node.js/Express.js backend, and MongoDB for data persistence. PDF parsing extracts resume content, which is analyzed against job descriptions, with the Gemini API powering intelligent resume optimization suggestions.

**Engineering decisions:** Offloading the natural-language reasoning to the Gemini API allowed the project to focus engineering effort on parsing accuracy, scoring logic, and UX rather than building an NLP model from scratch.

| Attribute | Details |
|---|---|
| Stack | React.js, Node.js, Express.js, MongoDB, Tailwind CSS, Gemini API |
| Scale | Personal/academic project |
| Performance | Not formally benchmarked |
| Security | Standard MERN application practices |
| Impact | Automated, AI-driven resume feedback and ATS optimization |
| Repository | [github.com/Abhinaw321](https://github.com/Abhinaw321) |
