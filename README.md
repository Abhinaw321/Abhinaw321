<summary><b>📄 IntelliHire AI — AI-Powered Resume Analyzer & ATS Optimizer</b></summary>

<br/>

An AI-powered resume analyzer providing ATS scoring and personalized improvement suggestions through PDF parsing, job-description matching, and generative AI.

**Why it matters:**  
IntelliHire AI helps users identify resume-to-job-description gaps and receive actionable AI-generated feedback.

**Technical implementation:**  
The frontend uses React.js and Tailwind CSS. The backend uses Node.js and Express.js with MongoDB for persistence. PDF parsing extracts resume content, while Gemini API provides intelligent resume analysis and optimization suggestions.

**Engineering decisions:**  
Using Gemini API for natural-language reasoning allowed the application to focus engineering effort on document parsing, matching logic, scoring, and user experience.
